# MINI-Project-on-Trends-Analysis-dashboard

Project Objective:
Trends Customer Purchase Analysis Dashboard built in Power BI to analyze customer behavior, category trends, payment preferences, and seasonal patterns. IncludesI cards, slicers , interactive filters, and visual insights to support data-driven business decisions.

DATASET USED:
- <a href="https://www.kaggle.com/datasets/iamsouravbanerjee/customer-shopping-trends-dataset">Dataset<a/a>

 Question :
How can customer purchase data be analyzed to identify buying patterns, category performance, payment preferences, and the impact of discounts?

 Process :
Collected and cleaned customer purchase data, created DAX measures, and designed interactive Power BI visuals with KPIs, filters, and trend analysis.

DASHBOARD:



Final Conclusion :
The dashboard reveals key customer trends, top categories, preferred payment methods, and seasonal impacts, enabling data-driven decisions and improved business strategies.
